# ADAL

**Адал білім — нақты нәтиже.** ADAL оқушының кодын ғана емес, оны түсіндіру және өзгерту қабілетін бағалайтын білім беру платформасының MVP нұсқасы.

## Мүмкіндіктер

- Қазақ тіліндегі бейімделгіш React интерфейсі және Monaco код редакторы (Python, C++, Java).
- Рөлге негізделген тіркелу/кіру: оқушы және мұғалім.
- Мұғалім тапсырма мен мерзімін береді, жұмысты қарап, бағалау есебін CSV түрінде жүктейді.
- Алғаш іске қосылғанда Python, C++ және Java бойынша 6 дайын тапсырма дерекқорға автоматты қосылып, оқушылар кабинетінде көрінеді.
- Оқушы кодын сақтап, тапсырып, алгоритмдік сұрақтарға жауап береді.
- Баға 30/25/20/15/10 үлестері бойынша есептеледі. AI детекторы жоқ; күдік бағаны автоматты өзгертпейді.
- Код нұсқалары уақыт белгісімен сақталады. Өзгерістер тарихы оқу процесін түсінуге көмектеседі, авторлықты дәлелдемейді.

## Іске қосу

Python 3.11+ және Node.js 20+ қажет.

### API

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

API: http://localhost:8000 (құжаттама: `/docs`). SQLite дерегі `backend/adal.db` ішінде жасалады. Өндірісте `ADAL_SECRET` мәнін орнатып, HTTPS/CORS және дерекқор backup саясатын баптаңыз.

Мұғалім ретінде тіркелмес бұрын API іске қосылатын PowerShell терезесінде `$env:ADAL_TEACHER_CODE = "local-teacher-code"` мәнін орнатыңыз. Тіркелу кезінде осы кодты енгізіңіз.

### Интерфейс

```powershell
cd frontend
npm install
npm run dev
```

Vite API-ді `http://localhost:8000` мекенжайына бағыттайды. Бірінші беттен оқушы не мұғалім ретінде аккаунт ашыңыз.

## Қауіпсіз орындау туралы

Бұл MVP оқушы кодын серверде орындамайды. Код орындау API-де әдейі қолжетімсіз: қауіпті кодты негізгі сервер процесінде іске қосуға болмайды. Нақты орындауды қосу үшін желісі өшірілген, CPU/жад/уақыт лимиттері бар контейнерлік runner (мысалы, бөлек Docker worker) және операциялық мониторинг қажет. Әзірше бағалауда орындалу бөлігі мұғалімге арналған қолмен қойылатын ұпаймен беріледі. Бұл код орындалды деген жалған мәлімдемені болдырмайды.

## Интернетке жариялау

Жоба бір Docker web қызметі ретінде жариялануға дайын. `render.yaml` Render Blueprint, `Dockerfile` интерфейс пен API-ді бір қызметке біріктіреді.

1. GitHub-та осы буманы репозиторийге жүктеңіз.
2. Render Dashboard-та **New → Blueprint** арқылы репозиторийді таңдаңыз.
3. Тұрақты сақтау үшін PostgreSQL дерекқорын бөлек дайындап, оның connection string мәнін Render Blueprint сұраған `DATABASE_URL` өрісіне енгізіңіз. SQLite тек жергілікті іске қосуға арналған; тегін хостингтің файл жүйесінде сақталған деректер қызмет қайта іске қосылғанда жоғалуы мүмкін.
4. Render автоматты URL үүсіріп, `https://<қызмет-атауы>.onrender.com` мекенжайында жариялайды. Алғашқы іске қосылғанда алты тапсырма автоматты қосылады.

`ADAL_SECRET` және мұғалімге арналған `ADAL_TEACHER_CODE` мәндерін Blueprint өзі жасайды. Мұғалім тіркелгенде Render Dashboard-тағы кодты мұғалімдерге жеке беріңіз. `DATABASE_URL` құпиясын репозиторийге немесе README-ге жазбаңыз. Render web services интернетке `onrender.com` мекенжайымен қолжетімді; тұрақты disk қызметтері Render-де ақылы жоспарды қажет етеді, сондықтан бұл конфигурация SQLite орнына PostgreSQL URL күтеді.
